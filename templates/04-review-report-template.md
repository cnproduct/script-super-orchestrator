# 剧本主编级审稿与诊断报告模板 (Review Report Template)

## 一、 评审总览与定级
- **剧本名称**：
- **评定等级**：【 S+ / S / A / B / C 】
  - *S+：现象级爆款底子，人物饱满，卡点极致，可直接进入分镜制作*
  - *S ：优秀成熟稿件，需微调 1-2 处对白去水*
  - *A ：合格稿，但反派偏扁平或中段节奏有注水现象*
  - *B ：严重缺陷，存在说明性台词或主角被动问题，需重构大纲*
  - *C ：不及格，触碰编剧死罪，建议推翻重写*
