# 人物小传与角色网络卡模板 (Character Bible Template)

## 一、 主角基础档案
- **姓名**：
- **年龄 / 职业**：
- **视觉标签 / 标志性服饰**：（例：白衬衫袖口卷起，腰间别着黄铜卷尺，眼神疲惫但倔强）
- **核心身份危机**：（例：大城市被裁总监假装衣锦还乡的落魄海归）

## 二、 角色内心三角弧光 (The Arc)
1. **内在创伤 (Ghost / Wound)**：过去发生过什么毁灭性事件？导致了他什么根深蒂固的错误认知？
2. **表面欲求 (Want / False Goal)**：他在第一幕以为自己拼命想要什么？（例：必须把老茶铺改成洋气极简咖啡馆向外人证明自己）
3. **真实内在需要 (Need / Spiritual Growth)**：他在第三幕必须顿悟什么才能获得灵魂救赎？（例：理解外公竹椅里的人间烟火与温情陪伴）
4. **阿喀琉斯之踵 (Fatal Flaw)**：在极端压力下，他会本能犯下的最严重错误是什么？

## 三、 对立面反派矩阵 (Villain Matrix)
| 反派层级 | 角色姓名 | 表面身份与对立点 | 核心行动策略 | 真实内在动机与合理性 |
| :--- | :--- | :--- | :--- | :--- |
| **第一层：日常阻力** | 例：邻居挑刺者 | 市井生活刁难、讽刺洋玩意 | 大嗓门讽刺、当众拆台 | 嘴硬心软、护食、怕老铺被毁 |
| **第二层：利益对手** | 例：商业中介 | 收购腾退代理人 | 限期逼迁、以违约金施压 | 拿提成指标、信奉商业效率 |
| **第三层：观念对立** | 例：前公司主管/体制 | 资本工具人裁员机制 | 抛弃无价值者 | 优胜劣汰冷血逻辑 |

- **情感锚点 / 救赎者**：（如邻里长辈，用一顿热锅盔打破阶层虚荣）
